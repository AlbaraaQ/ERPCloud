1. افتح `00_OVERVIEW.md` — يشرح الأولويات والسوق

3. اقرأ وثيقة الرقم — فيها ترحيل + API + UI + اختبارات
4. نفّذ بنفس بوابات المراحل: مصدر + تسمية + ترحيل + صلاحية + اختبار + شاشة + دفعة + تعليق

## مقترح R18 (4 أسابيع)

**R18 = 01 + 02 + 03** — بنوك + OCR + سلة = أعلى ROI، يفتح باب الاشتراكات فوراً.

ثم R19 = 04 + 05 (موافقات + حقول مخصصة)
ثم R20 = 06 + 07 (أوفلاين + مدد/ميسر)

## ملاحظات تنفيذ

- الترحيل `0096` استُخدم لـ Bank Feeds و`0097` لـ OCR و`0098` لتحصين RLS؛ تكامل التجارة الإلكترونية يبدأ من `0099`. المرحلة 10 تستخدم `0106`، والمرحلة 11 `0107`، والمرحلة 12 `0108`، والمرحلة 13 `0109`. التالي الحر `0110`.
- كل صلاحية جديدة تُضاف في `packages/contracts/src/permissions.ts` + ترحيل idempotent + اختبار `permission-codes.spec.ts`
- كل شاشة جديدة يجب أن تكون مسار حقيقي ويقيسها `navigation.spec.ts`
- لا `git add -A` — مسارات صريحة فقط
- لا شيء من `apps/admin*|apps/customer*` في PR
- تعليق عربي بعد كل مرحلة على PR #6
