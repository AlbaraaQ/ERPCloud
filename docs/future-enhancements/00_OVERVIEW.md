## كيف تُستخدم هذه الوثائق في محادثة جديدة؟

كل وثيقة تتبع نفس قالب بوابات المراحل 5-11:
1. **المشكلة والسوق** — لماذا نحتاجها + من يملكها
2. **النطاق** — ما يدخل وما لا يدخل
3. **التصميم التقني** — جداول + API + صلاحيات + UI
4. **معايير القبول** — اختبارات + سكربت تحقق حي
5. **الجهد والاعتماديات**

في المحادثة الجديدة: افتح `00_OVERVIEW` → اختر رقم → اقرأ وثيقته → نفّذ بنفس قواعد `docs/roadmap/README.md` §4 (مصدر + تسمية + ترحيل + صلاحية + اختبار + شاشة + دفعة).

## ميزتك التنافسية الحالية (حافظ عليها)

- **عموديات لا يملكها أحد:** مرسى (دور مراكب + حضور)، تفصيل (مقاسات)، نظارات (OD/OS)، مشاريع (BOQ + مراحل)، شيكات، عهدة إغلاق
- **مطابقة ديسكتوب بالسطر:** كل شاشة لها `frmXXX.xaml:123` — ثقة للمحاسبين القدامى
- **لوحة منصة كاملة:** P-C1..12 + بريد + إعلانات + دعم + نسخ خارج القاعدة + مطور + تحليلات
- **تقرير PDF جاهز:** HTML + `@page` + طباعة متصفح (R17)

لا تكسر هذه — ابنِ فوقها.
