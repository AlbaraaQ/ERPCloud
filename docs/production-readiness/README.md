# Production Readiness — تدقيق الجاهزية للنشر

> **مجلد العمل.** وُلد من جلسة مراجعة طلب فيها المالك قائمةً من 15 بندًا عن الستايل
> والشاشات الناقصة وأخطاء التشغيل والجاهزية للإنتاج. هذا المجلد هو **مصدر الحقيقة**
> لتلك القائمة: ما تم فحصه، وما ثبت سببه، وبأي ترتيب يُصلَح.
>
> **كيف تُكمل في محادثة جديدة:** اقرأ `01-AUDIT.md` ثم `02-ROOT-CAUSES.md` ثم
> `03-PLAN.md`. الثلاثة تكفي لاستئناف العمل بلا سياق سابق. `04-BACKLOG.md` يذكر ما
> لم يُنجَز صراحة، و`05-DECISIONS.md` يذكر ما يحتاج قرار المالك.

## البنود كما وردت من المالك، وحالة كلٍّ منها

| # | البند | الحالة بعد الفحص |
|---|---|---|
| 1 | الاستايل غير مضبوط والتصميم غير احترافي | **مفتوح** — يحتاج جولة تصميم |
| 2 | الشريط الجانبي غير احترافي وفيه مشاكل | **مفتوح** — يحتاج جولة تصميم |
| 3 | شاشات staff غير موجودة (بطاقة المنشأة، إضافة مستخدم والصلاحيات) | **الشاشات موجودة** — الخلل تشغيلي لا بنيوي، انظر `02-ROOT-CAUSES.md` |
| 4 | خطأ عند حفظ الفواتير في نقطة البيع | **السبب مُثبَت**: `feature.pos = false` لهذا المستأجر |
| 5 | العميل الافتراضي عميل عام والمورد مورد عام | **مُثبَت**: `GET /parties` يُعيد `[]` — لا طرف عام مُبذور |
| 6 | عميل عام → ضريبية مبسّطة، وصاحب رقم ضريبي → ضريبية | **المنطق منجز في الـ API**؛ الناقص هو الطرف العام نفسه |
| 7 | شاشة الإشعارات لا تفتح، وشاشات الأوفلاين | **مُثبَت**: الإشعارات تفتح وتُعيد `data: []`؛ الأوفلاين تحتاج فحصًا حيًّا |
| 8 | لا خيار "نسيت كلمة السر" | **مُثبَت**: لا endpoint لذلك في الـ API إطلاقًا |
| 9 | شاشة الترخيص لا تعرض بياناتها، وطلب المساعدة | **السبب مُثبَت**: `GET /billing/activation-requests` → 500 |
| 10 | لا داعي لشاشتي "عن البرنامج" و"تحديث البرنامج" | **مُثبَت**: مفهومان مكتبيان في نظام سحابي |
| 11 | إعدادات البريد يجب أن تدعم resend | **مفتوح** — يحتاج قرارًا في `05-DECISIONS.md` |
| 12 | شاشة إعدادات المساعد AI لا تدعم api | **جزئيًّا**: `PUT /ai/settings` موجود؛ ما لا يدعمه هو مفتاح المزوّد |
| 13 | شاشات لا يجوز أن تكون في الأنظمة السحابية | **مفتوح** — قائمة مقترحة في `01-AUDIT.md` |
| 14 | كل شيء جاهز للإنتاج، بلا بيانات تطوير | **مستوفى جزئيًّا** — لا `USE_MOCKS` ولا بيانات تجريبية مكتوبة |
| 15 | وكلاء متعددون بالتوازي | **غير قابل للتنفيذ** — وكيل واحد لكل جلسة؛ انظر `05-DECISIONS.md` |
